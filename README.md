# NAKEEMA

Plataforma web para la gestión integral de servicios, técnicos, inventario y experiencia del cliente. El sistema está diseñado para centralizar procesos operativos y brindar una experiencia más organizada tanto para administradores, técnicos como para usuarios finales.

## 🌐 Demo en línea

Puedes probar la aplicación aquí:

- [Netlify - NAKEEMA](https://nakeemawebapp.netlify.app)

## ✨ Características principales

- Registro y gestión de usuarios por roles
- Panel administrativo para supervisar operaciones
- Gestión de técnicos y servicios
- Seguimiento de inventario y recursos
- Vista para clientes con acceso a información relevante
- Módulos de perfil, reportes y satisfacción del servicio

## 🛠️ Tecnologías utilizadas

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Supabase
- Cypress para pruebas

## ▶️ Ejecutar localmente

1. Instala las dependencias:
   ```bash
   npm install
   ```

2. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```

3. Abre la aplicación en tu navegador:
   ```text
   http://localhost:3000
   ```

## ✅ Pruebas

Para ejecutar las pruebas automatizadas:

```bash
npm run test
```

## 📁 Estructura del proyecto

- app/: páginas y vistas principales del sistema
- components/: componentes reutilizables de la interfaz
- app/api/: endpoints de backend y lógica de integración
- supabase/: configuración y migraciones de base de datos

## 📌 Propósito del proyecto

NAKEEMAF busca transformar la forma en que se administran servicios técnicos y soporte al cliente, ofreciendo una solución moderna, escalable y fácil de usar para organizaciones que requieren control, trazabilidad y organización operativa.
